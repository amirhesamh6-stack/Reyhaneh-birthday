سایت تبریک تولد ریحانه حقیقی

برای اجرا:
1) فایل ZIP را استخراج کنید.
2) فایل index.html را در مرورگر باز کنید.
3) پوشه assets را کنار index.html نگه دارید؛ فایل صوتی داخل آن است.

برای انتشار در GitHub Pages:
- محتوای این پوشه را در ریشه یک مخزن GitHub بارگذاری کنید.
- از Settings > Pages، گزینه Deploy from a branch را انتخاب کنید و شاخه main و پوشه /(root) را تنظیم کنید.
- پس از انتشار، لینک سایت در بخش Pages نمایش داده می‌شود.

نکته: فونت Vazirmatn از Google Fonts بارگیری می‌شود؛ برای نمایش آن اینترنت لازم است. اگر مرورگر فایل صوتی را پخش نکرد، از یک میزبان استاتیک مثل GitHub Pages استفاده کنید.
